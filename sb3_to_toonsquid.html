What gets converted?

The port creates a ToonSquid-oriented import bundle with extracted artwork/audio, sprite order and placement metadata, and a conversion report. It also translates simple Scratch motion/visibility/size blocks into readable porting notes where possible. Complex logic, sensing, clones, broadcasts, and interactive Scratch behavior need to be rebuilt manually in ToonSquid.

Important

The export is a porting package, not a native .tsproj file. A valid native ToonSquid project requires its actual project schema; this page does not fake that by renaming a ZIP.

Your file is processed in this browser and is not uploaded. ZIP support is loaded from JSDelivr when needed, so an internet connection is required for the library.
